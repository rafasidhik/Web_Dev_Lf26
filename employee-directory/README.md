# Task 06: Employee Directory

A responsive employee directory web app built with TypeScript for the μLearn Web Development Challenge.

## Overview
An interactive employee directory demonstrating TypeScript fundamentals and static type safety: defining structured data models with interfaces and type aliases, rendering typed employee records to the DOM, implementing type-safe search and filtering functionality, and organizing code into maintainable, strongly-typed logic.

## Features
- Strong static type safety using TypeScript interfaces and type aliases for employee data structures
- Dynamic rendering of employee profiles from a typed dataset with avatar initials and department tags
- Real-time search functionality filtering across name, role, department, and email
- Type-safe search logic maintaining consistency with employee interface properties
- Live search result counter and accessible status updates
- Graceful empty state handling when no matching employees are found
- Fully responsive layout across mobile, tablet, and desktop devices

## Tech Stack
- HTML5
- CSS3
- TypeScript

## Getting Started

### Prerequisites
- Modern web browser
- Git
- Node.js & npm

### Installation
```bash
git clone https://github.com/rafasidhik/Web_Dev_Lf26.git
cd Web_Dev_Lf26/employee-directory
npm install
```

### Run Locally
Compile TypeScript and serve the project:
```bash
npm run build
npm start
```
Or simply open `index.html` in your browser.
