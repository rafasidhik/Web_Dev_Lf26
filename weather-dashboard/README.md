# Task 04: Weather Dashboard

A responsive weather dashboard web app built with vanilla JavaScript for the µLearn Web Development Challenge.

## Overview
An interactive weather dashboard demonstrating asynchronous JavaScript and API integration: fetching live meteorological data with `fetch()` and `async/await`, rendering current weather conditions and a 5-day forecast, and managing loading states and error handling.

## Features
- Real-time weather data fetching using `fetch()` and `async/await` from Open-Meteo API
- Geocoding API integration to search weather by city name
- Dynamic rendering of current weather (temperature, condition, feels like, humidity, wind speed, precipitation, and date)
- 5-Day forecast outlook with weather icons, temperatures, and rain probability
- Loading state indicator during API requests
- Graceful error handling for invalid cities and failed network requests
- Fully responsive layout across mobile, tablet, and desktop devices
- Footer section with μID credit

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Open-Meteo API
