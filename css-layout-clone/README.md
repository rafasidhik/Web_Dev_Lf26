# Task 02: Website Layout Clone

A responsive homepage clone built with pure HTML5 and CSS3 for the µLearn Web Development Challenge.

## Overview
Recreation of the "Flow" landing page from scratch, focusing on CSS layout techniques using CSS Grid, Flexbox, and media queries without any external frameworks.

## Features
- Flexbox & Grid layout
- Fully responsive (Mobile, Tablet, Desktop)
- Smooth hover effects
- Hero section with μID credit

## Tech Stack
- HTML5
- CSS3

## Getting Started

### Prerequisites
- Modern web browser
- Git

### Installation
```bash
git clone https://github.com/rafasidhik/Web_Dev_Lf26.git
cd Web_Dev_Lf26/css-layout-clone
```

### Run Locally
Simply open `index.html` in your browser.
