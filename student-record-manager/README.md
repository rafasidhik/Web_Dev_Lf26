# Task 03: Student Record Manager

A dynamic student record management web app built with vanilla JavaScript for the µLearn Web Development Challenge.

## Overview
An interactive academic records dashboard demonstrating core JavaScript fundamentals: array of objects manipulation, dynamic DOM rendering, real-time search, multi-criteria filtering, sorting, and live statistical calculations.

## Features
- Dynamic rendering of student records from an array of objects using DOM manipulation
- Real-time search by student name
- Multi-criteria filtering by course and minimum marks
- Sorting by student name (A-Z, Z-A) and marks (High-Low, Low-High)
- Live performance statistics (total students, average marks, and top performer) calculated with `reduce()`
- Color-coded performance badges and empty state handling
- Dataset and footer section with μID credit

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla JS)
