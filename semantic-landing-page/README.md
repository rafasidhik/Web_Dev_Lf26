# Task 01: Semantic HTML Landing Page

A clean and accessible landing page built with pure semantic HTML5 for the µLearn Web Development Challenge.

## Overview
A landing page for "EcoConnect" structured with semantic HTML5 elements rather than generic `div` tags, focusing on accessibility, clean heading hierarchy, and an accessible contact form from the start.

## Features
- Semantic HTML5 structure (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)
- Clean heading hierarchy (single `<h1>` with nested `<h2>` and `<h3>` tags)
- Accessible contact form with proper `<label>` elements and sensible input types
- Meaningful image `alt` text and ARIA attributes
- Footer section with μID credit

## Tech Stack
- HTML5
